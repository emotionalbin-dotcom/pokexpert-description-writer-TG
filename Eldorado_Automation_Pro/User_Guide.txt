DGowdru PoGo Description Writer - User Guide

* Extract all files from the ZIP folder into a single folder on your computer
* Double-click on Description_Writer_Protected.exe to launch the tool
* The background interceptor connection will automatically start silently!
* A console window will appear asking for your License Key
* Paste your valid License Key and press Enter
* Open Google Chrome and log into the Pokemon Go Web Store (or related PoGo service)
* The Description Writer will automatically detect your Pokemon Go account data!
* It will extract your full inventory, stats, and shiny history
* A formatted "eldorado_listings.txt" file will be created for you to copy and paste onto your Eldorado store
* Contact DGowdru support if your key is rejected or you need a new license
